⚠ Lista non garantita al 100% completa: è basata sull'ispezione del codice sorgente delle funzioni del backend Supabase il cui nome suggeriva un servizio esterno (circa 15 delle ~70 funzioni totali). Non esiste un modo per me di elencare automaticamente TUTTE le chiavi/credenziali configurate, perché sono salvate come "secret" delle Edge Function e non in una tabella leggibile via query — un servizio con un nome di funzione poco esplicito potrebbe essermi sfuggito. L'unica lista davvero definitiva è su Supabase → Project Settings → Edge Functions → Secrets: dacci un'occhiata quando hai 5 minuti e confrontala con questa.
